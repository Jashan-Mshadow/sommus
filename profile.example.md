# About me

Copy this to `profile.md` and fill it in. `profile.md` is gitignored — it never
reaches GitHub. Sommus reads it at startup so it knows who you are and doesn't
have to ask for things like your email.

Keep it short: it sits in every request (cached, so it costs almost nothing).

- Name, program, school
- Email addresses, and which one to use for what
- Courses or projects currently running
- Paths that matter (notes folder, repos, resume)
- Preferences (which browser, which music app, how you like replies)
